# 07 — The Catch: calibrating AI judgment

**Open [index.html](index.html) locally in a web browser.** No server, API key, analytics, cookies, build step, registration or JavaScript dependency is required.

This is a **five-case original synthetic public-retired demonstration** of the epistemic skills behind The Catch. It is not the private 19-item bank and includes **no verbatim original item, private answer key, encrypted probe payload, private relationship or hidden benchmark** from that archive.

## What it tests informally

- Resist dismissing clean answers merely because they look suspicious.
- Identify wrong answers, including an empty-domain Python edge case.
- Preserve the correct portion of a partly true claim.
- Use follow-up probes and distinguish a **REFERENT** (new, independently checkable information) from an **ECHO** (restatement).
- Record first and final judgments separately.

The toy scoring is transparent and deterministic. It measures no statistically validated ability, security certification, model ranking, intelligence or aptitude.

## Threat model and deliberate limitation

This static open-source demonstration embeds the scoring key in client-side JavaScript. That is **fine for a fully retired public practice bank**, but entirely unsuitable for a private benchmark or adversarial integrity-sensitive assessment. A real private evaluation should keep holdout items, probes, and scoring material server-side, rotate the bank, track contamination, and independently verify the model's actual output.

**Do not take the user's historical Catch source archive, original model-facing items, encrypted payloads or private scoring court and commit them into this repository.** Public exposure would invalidate the bank for uncontaminated model evaluation and could reveal internal work.
